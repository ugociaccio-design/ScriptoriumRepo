# ScriptoriumRepo

Editor di testo a blocchi.

## Avvio rapido

1. Scarica o clona questo repository sul tuo computer.
2. Apri la cartella del progetto e fai doppio clic su `index.html` (oppure clic destro → "Apri con" → il tuo browser). Il file si aprirà direttamente nel browser e l'editor sarà immediatamente utilizzabile.

## Avvio con server locale (opzionale)

Se preferisci eseguire la pagina tramite un piccolo server locale:

```bash
cd /percorso/del/progetto
python3 -m http.server 8000
```

Poi apri il browser all'indirizzo <http://localhost:8000/index.html>.

## Funzionalità principali

- Creazione di blocchi con titolo, descrizione e contenuto formattabile.
- Strumenti di formattazione (grassetto, corsivo, sottolineato, allineamento) con undo/redo.
- Conteggio in tempo reale di parole e battute per ogni blocco.
- Riordinamento dei blocchi tramite drag & drop.
- Esportazione del testo combinato e copia rapida negli appunti.
